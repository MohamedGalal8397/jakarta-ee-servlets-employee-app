# jakarta-ee-servlets-employee-app

Employee web app with Jakarta EE servlets, sessions, JAX-RS and a JDBC DAO layer on PostgreSQL.

**Stack:** Jakarta EE, Servlets, JDBC, PostgreSQL, Maven

## Run

```bash
```bash
mvn package
```

## Configuration

Credentials are read from environment variables (`DB_PASSWORD`, `RABBITMQ_PASSWORD`, `MINIO_SECRET_KEY`); the defaults in the config are for a local development setup only.
